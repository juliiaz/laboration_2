# Frågor & Svar om git
### Vad är skillnaden mellan git add och git commit?
Git add förbereder dina ändringar, medan git commit sparar dom permanent i historiken

### Varför använder man branches istället för att jobba direkt i main?
Främst för att kunna utveckla och testa nya ändringar utan att påverka koden i main

### Vad händer rent praktiskt när man gör en merge?
Ändringarna från en branch slås ihop in i en annan branch

### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
Pusha till GitHub = Man skickar sina commits till ett repository på GitHub. Publicera på t.ex. Netlify = Man gör webbplatsen tillgänglig på webben

### Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?
Man skapar en fil som heter .gitignore i projektets rotmapp och skriver in vilken fil som ska exkluderas från versionshanteringen
